仅探索集中带标签的记录；按最高概率分为五箱。细线为平均最高概率，实柱为样本正确率；小样本不能证明校准。

使用留出集检查门槛

导入时给记录标记 split: "holdout"。先在探索集选择门槛，再点击下方检查。反复查看会污染留出判断；换门槛后旧结果自动失效。

输入 → 选择问题 → 调门槛 → 检查逐条结果 → 导出报告／保存项目；重开后导入项目继续。浏览器不自动持久保存输入。
